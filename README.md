# Meta Lead Ads – React Native

This project Meta Lead Ads with a React Native mobile app. It uses a Node.js and Express backend to retrieve test leads and Socket.IO to send updates to the app.

### Tech Stack
- React Native, Expo, TypeScript
- Node.js, Express.js
- Socket.IO
- Meta Graph API

### Setup

**Backend**
```bash
cd backend
npm install
```
Add your required environment variables to a local `.env` file, then start the backend using the script in `package.json`.

**Mobile App**
```bash
cd mobile
npm install
npx expo start
```

Make sure the app is configured to connect to your running backend.
